# AgentPM

## Adaptive Multi-Agent Delivery Governance Platform

AgentPM is an AI-powered Project Management Office built using the Open Agentic Web framework.

Instead of relying on a single assistant, AgentPM uses a hierarchy of specialized agents that collaborate to plan, govern, secure, and optimize software delivery projects.

---

## Features

### Chief PM Agent

Coordinates the entire project lifecycle and activates only the required specialist agents.

### Solution Architect Agent

Generates architecture blueprints and recommends:

- Cloud platform
- Database
- Framework
- APIs
- Deployment model

### Developer Manager Agent

Creates:

- Work breakdown structure
- Development plans
- Resource recommendations
- Technical implementation strategy

### QA Manager Agent

Generates:

- Test strategy
- Functional testing plans
- Quality validation approach

### Security Tester Agent

Performs:

- OWASP Top 10 review
- Security assessment
- Vulnerability analysis
- Risk recommendations

---

## Dynamic Agent Activation

AgentPM activates only the required agents based on:

- Budget
- Timeline
- Project size
- Security requirements
- Business risk

This reduces AI token consumption while maintaining planning quality.

### Example

Small Project:

Chief PM
→ Solution Architect
→ Developer Manager

Enterprise Banking Project:

Chief PM
→ Solution Architect
→ Developer Manager
→ QA Manager
→ Security Tester
